# Портфолио Полины Макаровой

Статический сайт для GitHub Pages: игры, тренажёры, сайты и приложения, сделанные с ИИ.

- `index.html`, `css/`, `js/app.js` — сайт.
- `js/data.js` — список проектов. Новый проект: добавьте объект и положите `media/<slug>.mp4` и `media/<slug>.jpg`.
- `media/teaser-<slug>.mp4` — короткие ролики для мозаики на первом экране.
- `play/<slug>/` — веб-сборки игр, они запускаются прямо на сайте.

Локальный просмотр: `python3 -m http.server` в этой папке, затем http://localhost:8000.
